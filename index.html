Problem 1A

Read in data.

times <- read_csv(
  "https://manctsui.github.io/datasets/timesData.csv",
  show_col_types = FALSE
) |>
  mutate(
    rank = readr::parse_number(world_rank)
  ) |>
  group_by(country) |>
  mutate(
    Number_of_Universities = n()
  ) |>
  ungroup()

Problem 2B

The rank column by itself would not be a good candidate for a SharedData key. The data set contains multiple years and thus the same rank appears in multiple years so rank alone cannot uniquely identify an observation. Rank and year is a better choice.

add key column using mutate

times <- times |>
  mutate(
    ranking_key = paste(year, rank, sep = "-")
  )

Problem 2C

Create SharedData object.

shared_times <- SharedData$new(
  times,
  key = ~ranking_key,
  group = "university_rankings"
)

Create a filter slider based on university rank.

filter_slider(
  id = "rank_filter",
  label = "University Rank:",
  sharedData = shared_times,
  column = ~rank,
  step = 1
)
